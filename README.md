
# Geospatial Data Analysis

## Project Overview
This project performs Geospatial Data Analysis using Python.
It analyzes geographical locations, population distribution,
latitude and longitude of major Indian cities.

## Objectives
- Analyze geographical data.
- Study population distribution across cities.
- Visualize geographical coordinates.
- Create interactive maps of Indian cities.
- Understand spatial data patterns.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Folium

## Project Files
- geospatial_data.csv - Dataset containing city locations.
- geospatial_analysis.py - Data analysis and visualization.
- interactive_map.py - Interactive geographical map.
- requirements.txt - Required Python libraries.

## Cities Included
- Bengaluru
- Mumbai
- Delhi
- Chennai
- Hyderabad
- Kolkata
- Pune
- Jaipur

## Visualizations
- Population Distribution Bar Chart
- Geographical Distribution Scatter Plot
- Interactive Map of India

## How to Run

1. Install the required libraries:

   pip install -r requirements.txt

2. Run the analysis:

   python geospatial_analysis.py

3. Generate the interactive map:

   python interactive_map.py

## Conclusion
This project demonstrates how Python can be used
for geographical data analysis and visualization.
